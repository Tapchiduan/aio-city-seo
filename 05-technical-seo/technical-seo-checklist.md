# AIO CITY – Technical SEO Checklist

## Mục tiêu

Rà soát khả năng crawl, index, canonical, sitemap, metadata và trải nghiệm trang. Chỉ đánh dấu hoàn thành sau khi kiểm tra trực tiếp hoặc có bằng chứng từ công cụ.

## 1. Crawl và index

- [ ] Kiểm tra robots.txt của website.
- [ ] Kiểm tra sitemap XML và sitemap bài viết/trang.
- [ ] Kiểm tra URL trang dự án và 15 bài PR có trả HTTP 200.
- [ ] Đối chiếu trạng thái index trong Google Search Console.
- [ ] Kiểm tra trang bị noindex ngoài ý muốn.
- [ ] Kiểm tra canonical trỏ đúng URL chuẩn.
- [ ] Kiểm tra redirect, 404 và chuỗi chuyển hướng.

## 2. On-page

- [ ] Title riêng biệt, phản ánh đúng intent.
- [ ] Meta description riêng biệt và đúng nội dung.
- [ ] Một H1 chính rõ ràng.
- [ ] Heading phân cấp hợp lý.
- [ ] Ảnh có alt mô tả chính xác.
- [ ] Link nội bộ không hỏng.
- [ ] Không có nội dung trùng lặp gây cạnh tranh không cần thiết.

## 3. Structured data

- [ ] Kiểm tra schema hiện có trước khi thêm mới.
- [ ] Đảm bảo schema phản ánh nội dung hiển thị.
- [ ] Không thêm AggregateRating/Review nếu không có dữ liệu đánh giá hợp lệ.
- [ ] Kiểm tra lỗi bằng công cụ kiểm thử dữ liệu có cấu trúc phù hợp.

## 4. Hiệu suất và trải nghiệm

- [ ] Kiểm tra Core Web Vitals trong Search Console/PageSpeed Insights.
- [ ] Kiểm tra giao diện mobile.
- [ ] Kiểm tra kích thước ảnh và lazy loading.
- [ ] Kiểm tra layout shift và thành phần tải chậm.
- [ ] Không thay đổi Flatsome layout hoặc shortcode nếu chưa được yêu cầu.
